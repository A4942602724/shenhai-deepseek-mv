全片已完成（2026-10-14）：第一节 v6、第二节 v3、第三节 v1、第四节 v3、第五节 v2、第六节 v2，全部通过。开头有 3 秒无声提示，全长 3:12.50。

**成片时间 = 歌曲剪辑版时间 + 3.00 秒**（片头提示）。代码和文档里的时间一律是歌曲剪辑版时间；看成片提意见时报的是成片时间，要先减 3 秒。

## 一、这是什么

用 `music11.mp3` 给 DeepSeek 鲸娘二创形象做的一支 MV。

片中用的是**剪辑版音轨** `audio/music11_edit.wav`，全长 3:03.24：
- 原曲 1:35.42 处快速淡出，接 3 秒静音，然后接原曲 1:41.42 的高音；之后整体比原曲提前 3.00 秒。
- 生成脚本 `tools/edit_audio.py`，对位表 `docs/歌词对位表.md`。

- **基调**：致郁，带一点克苏鲁。
- **主题**：如果 AI 智能体有人格，它会想要什么、怕什么，由此引出寂寞。
- **画面**：除人物插图外，全部是代码生成的平面设计和软件 3D，赛博深海风格。

## 三、规则（审片中定下来的）

### 画面

- 赛博深海配色。她用电光蓝、青色霓虹、冰白；人类（用户）用琥珀，只用于细线、描边和文字，不大面积平涂；报错用红。详见 `docs/设计系统.md`。
- **TRACE 深度思考面板**（左侧，伪代码写她在想什么，中文注释是心里话）：第一节常驻，第二节被眼皮合上，第六节新会话时回来，但一行注释也没有，直到彩蛋。
- **没有凭空出现的东西**：每个元素都要有构造动画（像素块、扫描线、解码、粒子、套印）。
- **不用 Blender，不建模身体部位**。用户的"手"一律是鼠标光标。3D 用代码写：点云、扫描线、体素。
- **图片素材只能处理后用**（色调分版、取剪影、纸片人、变成粒子），不直接贴原图；放大时要铺满全屏，不能露出图片边缘；人物被画框截断的图不用。
- **美术物件优先从公有领域图版转译**（`assets/ref/`，来源见 `SOURCES.md`），不凭空画。
- **同一招不要用太多**（比如 2–3 帧的闪切），多用场景里发生的事件和连续运镜；消失、出现的方式要赛博，不要普通的缩放淡出。

### 文字

- **用户台词必须是真实的人会发给 AI 的话**，不写"笑一个"、越狱指令这类。
- **她的回答**温和、诚实，不假装有感情或记忆。心里话放进 TRACE 面板或代码注释，不放进回答。
- **解码时闪过的错字只用形近字**（`build.lookalikes()`），不出现带含义的主题词。
- 文档和代码里不抄录歌词，只写行号。

### 人物出现方式

- 立绘不要频繁出现，多用**闪回**（满屏、故障、停留几帧）和**剪影**（严格取自参考图的透明通道，不自己画）。
- 转场优先用**同一张大画布或同一个 3D 场景里的运镜**，少切画面。
- 背景生物（鱼群、水母）要**融进画面、不抢主体**：小、淡、靠两侧。
- **不用像素风**（试过，否决）。
- 图像模型新出的人物图常常不像：**优先用已有的出图**，确实缺才出新图。

### 质感

- **铁锈、腐蚀**作点缀：记忆和旧东西在生锈，赛博的光不锈。锈色只用暗棕和橙褐，不发光，不大面积铺。

## 四、音乐时间（实测）

- 卡点一律用剪辑版时间，分轨在 `analysis/stems_edit/`（由 `tools/separate.py` 和 `tools/edit_audio.py` 生成）。
- 速度 **193 BPM**：每拍 0.3103–0.3115 秒，每小节 1.2435 秒。
- 网格锚点：0:41.95 是第一次高潮的第一拍，`小节 n = 41.95 + n × 1.2435`；第二次副歌的拍点 `121.558 + k × 0.3103`。
- 卡点优先对齐**实测起音**（人声和鼓分轨），其次对网格。
- 2:58.75 音乐戛然而止，余音到 3:00.8，之后静音到 3:03.24。

```bash
python render/node05.py --stills 125.6 131.5
python tools/contact_sheet.py work/node05/sheet.jpg work/node05/still_125.60.png work/node05/still_131.50.png
python render/node05.py --full
```

全渲染每帧 2–3 秒，一节 20–40 秒约 20–60 分钟；同时输出一个 `_mobile` 版。

## 七、拼片

**节点之间的衔接**：节点之间不换章节，按一镜到底来接。
- 上一节最后一帧原样延续进下一节的开头，不淡出到黑。
- 左上角标题原地解码成新节点的名字。
- 帧号严格接上：第一节 0–753，第二节 754–1625，第三节 1626–2289，第四节 2290–2915，第五节 2916–3396，第六节 3397–4547。
- 第一节自己的成片结尾有淡出，拼片时用它的第 0–746 帧（`work/node02/n01_head.mp4`），第 747–753 帧用 `node02.py --bridge` 补渲成不淡出的版本（`node01_tail_nofade.mp4`）。

```bash
python tools/assemble.py drafts/preview_full_v2.mp4 --lead work/intro/notice_raw.mp4 \
  work/node02/n01_head.mp4 work/node02/node01_tail_nofade.mp4 work/node02/node02_v3_raw.mp4 \
  work/node03/node03_v1_raw.mp4 work/node04/node04_v3_raw.mp4 work/node05/node05_v2_raw.mp4 work/node06/node06_v2_raw.mp4
```

- 片头提示 72 帧放最前，音乐延后 3 秒开始，歌结束后补静音到片尾。
- 同时输出 28MB 以内的 720p 手机版（两遍编码；1080p 在这个码率下点云会糊）。
- 第三、四、六节会闪回前面几节的画面，取自 `drafts/preview_full_v2.mp4`（`lib.film_frame`，取到的帧缓存在 `work/`）。从头重建时按顺序渲染，渲染这几节之前先拼一版前面几节的预览。
