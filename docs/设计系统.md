# 设计系统 v3 ——"赛博深海"

2026-10-13 · 在 v2"代码版画"的基础上，按审片意见调整：配色更赛博、更精致，加入"深度思考"面板，沙盘用代码做 3D。

## 版面

| 区域 | 位置 | 内容 |
|---|---|---|
| 左侧 | x 48–600 | **TRACE 深度思考面板**，全片常驻 |
| 右侧三分之二 | 中心 x = 1250 | 主画面 |

**TRACE 面板**用伪代码逐行写出她此刻在想什么，像实时运行日志：

- 每行左边是时间戳。
- `>` 是调用，`<` 是她说出口的话，`!` 是被外界打断。
- 中文注释是她的内心独白。
- 最新三行是亮的，更早的行压暗。

**HUD**：

- 左上角：`NODE 01 召唤`
- 右上角：会话号和时间码
- 右下角：歌词行号
- 四个角：取景框角标

## 界面（照着用户的客户端改的赛博深色版）

- 深色玻璃底，加点阵网格。
- 用户消息：深色琥珀底、琥珀色细边框、琥珀色文字。
- 她的回复：宋体，前面是鲸鱼头像，加"深度求索中 / 已完成，用时 N 秒"。

## 构造动画：没有东西是凭空出现的

（`render/build.py`，v5 起全片遵守）

| 手法 | 用在什么上 | 过程 |
|---|---|---|
| `box_build` | 面板、输入框、按钮、她的回复框 | 角标先弹出，然后描边从四角往中间画，最后一条亮扫描线从上往下把底色"刷"进去，内容随后出现 |
| `decode` | 所有文字 | 乱码从左往右解码成正文，乱码字符用"鲸、海、深、渊、光、潮、汐……" |
| `scan_reveal` | 整块界面（客户端） | 带锯齿状数据块的扫描线扫过，扫过的地方界面出现 |
| `assemble` | 她的身影 | 粒子从深海升上来，聚合成剪影 |
| `print_run` | 她的版画 | 三个色版依次滑进套准位置，像印刷机印出来一样 |
| `mosaic_in` | 桌宠 | 大像素逐级变清晰（数据加载的感觉） |

| `pixel_build` | **左侧 TRACE 面板**（v6 起） | 像素块先沿外框顺时针拼一圈，然后从上往下带随机地落满；每块落下时闪一下青光，快落下的块会先闪烁出淡淡的残影；最后缝隙合拢成一整块玻璃面板 |

**消息气泡**：边框从说话人那一侧扫进来，底色跟在一条亮边后面填满，文字再解码出来。

## 用户 = 光标

（`render/cursors.py`，v6 起，取代"孩子画的笑脸"）

- 用户在她的世界里以**像素风鼠标光标**的形式存在：
  - 琥珀色描边、暗琥珀填充。
  - 由像素块逐个拼出来，每块落下时闪一下冰白。
  - 带 `user_0417` 这样的名字标签，类似多人协作软件里的光标。
  - 水面下有青色的倒影。
- 发消息时光标点击一下（下压，加一圈波纹），消息从光标处掉进水里。
- 远处还有一些小而暗的光标，表示用户有很多。
- 光标移到她上方时**变成手形**，就像鼠标停在一个可点击的东西上；随后手形光标穿过水面，在她头顶点一下。TRACE 面板写：`hover(self): cursor = hand  // 原来我是可以被点击的`。
- 沙盘里，同一只手形光标被拉伸成 **3D 体素**（点云），拖着她走：`drag(self, dx=0.8)`。

**手绘元素**：孩子的笑脸、鹈鹕都是一笔一笔画出来的。

## 沙盘 v2：激光雷达扫描

（`render/scene_sandbox_v2.py`，取代 v4 的实心低多边形）

- 一面青色的扫描面从左往右扫过，世界才被建出来。
- 沙地是扫描线；玩具和那只手是点云，带光照、轮廓光和雾。
- 扫完之后，物体识别框依次弹出：`toy_01 bucket 0.98`……
- 她是 **`toy_05  ?  0.51`**：琥珀色、闪烁、置信度很低。点"重新生成"之后，换成 `toy_06`。
